# Simple KNN Fruit Classifier

This example demonstrates a basic K-Nearest Neighbors (KNN) classification algorithm. It shows how a simple machine learning model can 'learn' from a small dataset of fruit features (weight, smoothness) and predict the type of a new, unseen fruit (apple or orange) based on its similarity to known examples.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
